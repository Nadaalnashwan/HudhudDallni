# Hudhud AI Smart Assistant 🐦🗺️

ميزة مساعد ذكي داخل تطبيق هدهد للخرائط: يفهم طلبك باللهجة السعودية، يقترح أماكن حقيقية بالرياض على الخريطة، يخطط طلعة من أكثر من محطة بالترتيب، يخليك تعدّل الخطة بسهولة، وبعد الزيارة يجمع ملاحظاتك ويصيغ تقييم ينشر داخل هدهد بموافقتك ويتعلم من تفضيلاتك.

## التشغيل

```bash
npm install
cp .env.example .env.local   # اختياري — بدون مفاتيح يشتغل Demo Mode
npm run dev
```

افتح http://localhost:3000

## Demo Mode

كل مفتاح اختياري، واللي ناقص يتحول تلقائياً لبديل تجريبي واضح (يظهر شريط «وضع تجريبي» فوق):

| الخدمة | مع المفتاح | بدون المفتاح |
|---|---|---|
| Google Places API (New) | أماكن حقيقية + صور + تقييمات Google | أماكن تجريبية بأسماء وهمية «(تجريبي)» موزعة على أحياء الرياض |
| Google Routes API | مسار قيادة فعلي + وقت مع الزحمة | خط مباشر + تقدير للمسافة والوقت |
| Maps JavaScript API | خريطة Google | خريطة OpenStreetMap (Leaflet) |
| Groq | فهم الطلبات وصياغة التقييمات بالـLLM | محلل قواعد للهجة السعودية + قالب تقييم |
| Supabase | حفظ في قاعدة البيانات | حفظ في المتصفح (localStorage) |

### تفعيل Google
فعّل في Google Cloud: **Places API (New)**، **Routes API**، **Maps JavaScript API**. حط مفتاح السيرفر في `GOOGLE_MAPS_API_KEY` ومفتاح المتصفح (مقيد بالدومين) في `NEXT_PUBLIC_GOOGLE_MAPS_BROWSER_KEY`.

### تفعيل Supabase
شغّل [`supabase/schema.sql`](supabase/schema.sql) في SQL Editor، وحط `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
سياسات RLS الحالية مناسبة للـMVP فقط (مستخدم مجهول بمعرّف جهاز) — شدّدها على `auth.uid()` لما تضيفون تسجيل دخول.

## رحلة المستخدم وكيف تنفذت

1. **اقتراحات جاهزة** — «أبي قهوة»، «أبي أتغدى»، «أبي أتعشى»، «أبي كوفي هادي»، «خطط لي طلعة» + أزرار الفئات أعلى الخريطة.
2. **توضيح ذكي** — سؤال واحد فقط إذا لزم (مسافة أو تقييم / هادي أو جلسات خارجية)، وما يسأل أبداً إذا الطلب فيه أكثر من محطة.
3. **اقتراحات على الخريطة** — بطاقات فيها الصورة، التقييم، العنوان، المسافة، **سبب الاختيار**، والبدائل كدبابيس رمادية على الخريطة.
4. **تخطيط متسلسل** — «نادي وبعده كوفي وبعده مطعم»: كل محطة تنبحث **قرب المحطة اللي قبلها** (مو قرب نقطة البداية)، وتنعرض كـ Pipeline مع رسم المسار ووقت كل مرحلة.
   - «غير الكوفي» ← يثبت النادي، يستبعد الكوفي الحالي، يختار كوفي جديد، **ثم يعيد اختيار المطعم قرب الكوفي الجديد**.
   - 📌 تثبيت محطة يمنع تغييرها حتى لو تغير اللي قبلها.
   - التعديل من الشات («ثبت النادي»، «شيل المطعم»، «ضيف حلا») أو من البطاقات أو من دبابيس الخريطة.
5. **تأكيد الزيارة** — بعد «ابدأ الطلعة» بـ30 دقيقة، أول ما يرجع المستخدم للتطبيق يسأله «زرت المكان فعلاً؟» (فيه زر «محاكاة الرجوع» للعرض).
6. **تحليل التجربة السلبية** — زحمة / أسعار مرتفعة / خدمة سيئة / ما يناسبني أو نص حر.
7. **صياغة ونشر التقييم** — الـAI يصيغ، المستخدم يعدّل، وما ينشر إلا بموافقته. ينشر في نظام تقييمات هدهد فقط؛ تقييمات Google تظهر منفصلة في صفحة المكان وما ننشر عليها شيء.
8. **تخصيص مستمر** — بموافقة صريحة نحفظ التفضيلات (مثلاً «زحمة» ← يفضّل الأماكن الهادية). المخطط يرفع الأماكن **الموصوفة** بأنها هادية فقط، ويقول بوضوح إذا ما عنده معلومة مؤكدة. تقدر تشوف وتمسح تفضيلاتك من ⚙️.

## دور الـAI

- **Groq (LLM):** يحوّل الرسالة إلى JSON منظم (`plan` / `clarify` / `modify` / `add`) — الأنشطة بالترتيب، الحي، الأولوية، التفضيلات — ويصيغ التقييمات. أي رد غير صالح يرجع تلقائياً لمحلل القواعد.
- **خوارزمية الاختيار (`src/lib/server/planner.ts`):** ما تعتمد على الـLLM لاختيار الأماكن. لكل محطة: بحث حول نقطة الارتكاز (المحطة السابقة) ثم ترتيب حسب القرب + التقييم + تطابق التفضيلات (أوزان حسب أولوية المستخدم)، مع استبعاد اللي رفضه.

```
  app/
    page.tsx                 الشاشة الرئيسية

    api/place/[id]           تفاصيل المكان وتقييمات Google
    api/review-draft         صياغة التقييم
    api/photo                بروكسي صور Google (يخفي المفتاح)
  components/
    HudhudApp.tsx            الحالة والتنسيق بين الخريطة والمساعد
    AssistantChat.tsx        الشات والاقتراحات وبطاقات الأماكن
    PlanPipeline.tsx         خطة الطلعة والتعديل
    PlaceSheet.tsx           صفحة المكان (تقييمات هدهد / Google)
    FeedbackFlow.tsx         متابعة ما بعد الزيارة
    map/                     Google Maps أو Leaflet
  lib/
    intent.ts                محلل اللهجة السعودية
    server/planner.ts        خوارزمية الاختيار
    server/places.ts         Places API + بيانات تجريبية
    server/routes.ts         Routes API + تقدير
    store.ts                 Supabase أو localStorage
supabase/schema.sql
```
