# Hudhud AI Smart Assistant

ميزة مساعد ذكي داخل تطبيق هدهد للخرائط: يفهم طلبك باللهجة السعودية، يقترح أماكن من قاعدة بيانات Supabase (بيانات تجريبية لأحياء الرياض) على الخريطة، يخطط طلعة من أكثر من محطة بالترتيب، يخليك تعدّل الخطة بسهولة، وبعد الزيارة يجمع ملاحظاتك ويصيغ تقييم ينشر داخل هدهد بموافقتك ويتعلم من تفضيلاتك.

## التشغيل

```bash
npm install
cp .env.example .env.local   # ثم عبّي رابط Supabase والـ publishable key
npm run dev
```

افتح http://localhost:3000

## قاعدة البيانات (Supabase)

التطبيق يقرأ من مخطط **`hudhud_demo`** في مشروع *Hudhud AI*: ‏420 مكان تجريبي (21 نوع فرعي × 10 أحياء × 2).
الإعدادات المطلوبة، نموذج الصلاحيات (RLS)، واستعلامات التحقق كلها في [`supabase/README.md`](supabase/README.md).

- **المفاتيح:** `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` فقط في `.env.local`. لا تستخدم مفتاح `service_role` أبداً.
- **الأماكن:** فلترة حقيقية في قاعدة البيانات بالفئة + النوع الفرعي + الحي. المسافة (Haversine بخط مستقيم) والترتيب يحسبها التطبيق.
- **التقييمات والتفضيلات:** كل مستخدم ياخذ جلسة Supabase مجهولة، وكل صف خاص مربوط بـ `auth.uid()` ومحمي بـ RLS.
- **لو القاعدة ما ردّت:** يظهر تنبيه واضح، وما يتحول التطبيق بصمت لبيانات ثانية.

## المصادر البديلة (اختيارية)

| الخدمة | مع المفتاح | بدون المفتاح |
|---|---|---|
| Supabase | أماكن `hudhud_demo` + حفظ التقييمات والتفضيلات | بيانات محلية تجريبية (مكتوب عليها «تجريبي») وحفظ على الجهاز |
| Google Gemini | فهم الطلبات وأي تسلسل أنشطة، التعديلات، تحليل الملاحظات، صياغة التقييمات، استخراج التفضيلات | محلل قواعد للهجة السعودية + قالب تقييم |
| Google Routes API | مسار قيادة فعلي + وقت القيادة | مسافات بخط مستقيم فقط — بدون أوقات مخترعة |
| Maps JavaScript API | خريطة Google | خريطة OpenStreetMap (Leaflet) |
| Google Places API | أماكن حقيقية (فقط إذا Supabase غير مهيأ) | — |

## الأنواع المدعومة

| الفئة | الأنواع الفرعية |
|---|---|
| مطاعم | إيطالي، وجبات سريعة، برجر، بيتزا، سعودي، شاورما، هندي، آسيوي، بحري، مشاوي |
| كوفيهات | قهوة مختصة، هادي، للمذاكرة، درايف ثرو |
| أندية | لياقة، نسائي |
| حلويات | مخبز، آيس كريم |

القاموس العربي/الإنجليزي ومرادفات اللهجة في [`src/lib/catalog.ts`](src/lib/catalog.ts). «أبي مطعم» = كل المطاعم، «أبي مطعم إيطالي» = فلتر `subcategory = italian` في القاعدة.

## رحلة المستخدم

1. **اقتراحات جاهزة وفلاتر** — أزرار الفئات أعلى الخريطة، وتحتها فلاتر الأنواع (الكل، إيطالي، برجر…) وكل فلتر يسوي استعلام فعلي.
2. **توضيح ذكي** — سؤال واحد فقط إذا لزم، وما يسأل إذا الطلب محدد أو فيه أكثر من محطة.
3. **اقتراحات على الخريطة** — بطاقات فيها صورة توضيحية للنوع، التقييم، الحي، المسافة، و**سبب الاختيار**، والبدائل كدبابيس رمادية.
4. **تخطيط متسلسل** — «أبي نادي في الصحافة وبعده كوفي قريب منه وبعده مطعم برجر قريب من الكوفي»: النادي من الصحافة، الكوفي حول النادي المختار، والمطعم حول الكوفي المختار.
5. **تعديل الخطة** — «غير الكوفي» (ويعيد اختيار اللي بعده)، «أبي كوفي أقرب»، «خل المطعم إيطالي»، «غير المطعم بس»، «ثبت النادي»، «أضف محل حلويات»، «شيل المطعم».
6. **بعد الزيارة** — تأكيد الزيارة ← التجربة والنجوم ← سبب التجربة السلبية ← تقييم يصيغه الـAI وتعدّله ← نشر **بموافقتك فقط** داخل هدهد (جدول `reviews`). الرفض ما ينشر شي.
7. **التخصيص** — بموافقة صريحة نحفظ: المطابخ والكوفيهات المفضلة، الأحياء، الميزانية، تفضيل القرب، والأشياء اللي تتجنبها. تقدر تشوفها وتمسحها من زر الإعدادات.

## دور الـAI

- **Gemini (`@google/genai`, `src/lib/server/gemini.ts`):** يستخرج نية منظمة لأي تسلسل أنشطة (لين 6 محطات، وممكن تتكرر الفئة)، النوع الفرعي، الحي، أولوية الترتيب، أوامر التعديل (تغيير النوع أو النشاط، أقرب، «بس»، إضافة بعد محطة معينة)، ويحلل ملاحظات ما بعد الزيارة، ويصيغ التقييمات، ويلتقط التفضيلات الثابتة اللي يقولها المستخدم (تنحفظ فقط بموافقته). كل رد يتحقق منه الكود: أي فئة أو نوع غير صالح ينحذف، وأي رد غير صالح يرجع لمحلل القواعد.
- **المفاتيح والتحويل:** `GEMINI_API_KEY_1..3` على السيرفر فقط. عند أعطال مؤقتة (5xx، انقطاع) يعيد المحاولة بمفتاح ثاني لحد 3 محاولات. عند تجاوز الحصة (429) يوقف ويستخدم محلل القواعد — ما يبدّل المفاتيح للالتفاف على الحصة.
- **الاختيار حتمي (`src/lib/server/planner.ts`):** الـAI ما يختار أماكن ولا يخترع تقييمات أو مسافات. كل محطة: استعلام بالفلاتر ← ترتيب حسب القرب من المحطة السابقة + التقييم + التفضيلات.

## الصور

صور توضيحية لكل نوع في `public/images/places/` من Unsplash (رخصة Unsplash) — المصادر في [`CREDITS.md`](public/images/places/CREDITS.md). مكتوب عليها «صورة توضيحية» لأنها مو صور للأماكن التجريبية نفسها.
